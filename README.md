Token Launch Radar: a comps-fitted value model over 758 protocols that ranks the 200 most promising pre-token launches, with a concrete farm plan (costs + time) for each and a sortable, filterable dashboard.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts
```

`main.ts` reads `/input/snapshot.json`, writes `/output/board.json`, `/output/data.js`, copies `dashboard/` and `screenshots/` to `/output`, and writes `/output/dossier.json`.
